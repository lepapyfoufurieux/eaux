Tester le site Eaux de Saurat sur votre ordinateur

Ce guide vous permet d'essayer le site chez vous, avec des données inventées. Pas besoin de connaissances techniques : vous allez surtout ouvrir des fichiers.

Vous ne pouvez rien casser. Tout reste sur votre ordinateur, le vrai site n'est pas touché.
  • Durée : environ 30 minutes la première fois (le temps des téléchargements), 2 minutes ensuite.
  • Il vous faut : un ordinateur Windows 10/11 ou Mac, Internet, et environ 5 Go de place libre.

Préparation

1 Installer Docker Desktop une seule fois

Docker Desktop est un logiciel gratuit qui fait fonctionner le site sur votre ordinateur.

  1. Allez sur docker.com/products/docker-desktop.
  2. Cliquez sur Download for Windows.
  3. Cliquez sur Download for Mac, puis choisissez Apple Silicon (Mac récent, puce M1, M2…) ou Intel (Mac plus ancien). En cas de doute : menu → À propos de ce Mac.
  4. Ouvrez le fichier téléchargé et suivez l'installation en gardant les choix proposés. Si on vous parle de « WSL », acceptez. Si on vous demande de redémarrer, faites-le.
  5. Ouvrez Docker Desktop. S'il propose de créer un compte, cliquez sur Skip (passer).
✅ C'est bon quand la fenêtre de Docker Desktop affiche Engine running en bas à gauche.

2 Télécharger le site une seule fois

Si vous avez déjà le dossier du site sur votre ordinateur (ce guide se trouve dedans), passez directement au point 3 ci-dessous.

  1. Cliquez sur ce lien : télécharger le site (fichier ZIP). Le fichier eaux-main.zip arrive dans votre dossier Téléchargements.
    Autre façon : sur la page github.com/lepapyfoufurieux/eaux, cliquez sur le bouton vert Code, puis sur Download ZIP.
  2. Décompressez-le : dans Téléchargements, faites un clic droit sur eaux-main.zip → Extraire tout… → Extraire. dans Téléchargements, double-cliquez sur eaux-main.zip (Safari le fait parfois tout seul : vous verrez alors directement un dossier eaux-main).
  3. Ouvrez le dossier eaux-main. S'il contient seulement un autre dossier eaux-main, ouvrez celui-ci : c'est lui, le dossier du site.
  4. Déplacez le dossier du site dans Documents pour le retrouver facilement.
✅ C'est bon quand le dossier du site contient backend, frontend et tester-le-site.

Lancer le site

3 Démarrer le site

Vérifiez d'abord que Docker Desktop est ouvert et affiche Engine running.

  1. Ouvrez le dossier tester-le-site.
  2. Double-cliquez sur demarrer-windows.
  3. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même.
  1. Ouvrez l'application Terminal (cherchez « Terminal » avec la loupe en haut à droite de l'écran).
  2. Copiez ce texte et collez-le dans le Terminal avec Cmd+V, sans appuyer sur Entrée :
    sh
  3. Ouvrez le dossier tester-le-site dans le Finder et faites glisser le fichier demarrer-mac.sh dans la fenêtre du Terminal.
  4. Appuyez sur Entrée.

Une fenêtre noire s'ouvre et beaucoup de texte défile. C'est normal, laissez faire. La première fois, cela prend 5 à 15 minutes.

✅ C'est bon quand la fenêtre affiche « C'est prêt ! » et que le site s'ouvre tout seul dans votre navigateur.

4 Passer l'avertissement du navigateur

Le navigateur affiche un message comme « Votre connexion n'est pas privée » ou « Attention : risque probable de sécurité ».

C'est normal et sans danger : le site est sur votre propre ordinateur, il n'a donc pas de certificat officiel.

  • Chrome, Edge : cliquez sur Paramètres avancés, puis Continuer vers le site localhost.
  • Firefox : cliquez sur Avancé…, puis Accepter le risque et poursuivre.
  • Safari : cliquez sur Afficher les détails, puis visiter ce site web.

Si le site ne s'est pas ouvert tout seul, tapez https://localhost dans la barre d'adresse.

✅ C'est bon quand vous voyez la carte du bassin du Saurat avec des points de couleur. 🎉

Tester

5 Essayer le site

Essayez librement, par exemple :

  • La carte : cliquez sur un point pour voir la photo. Déplacez la barre du temps en bas pour changer de période.
  • Le fil de l'eau : le plan de la rivière et de ses ruisseaux. Changez de mois pour voir les couleurs évoluer.
  • Publier une photo : prenez une photo avec votre téléphone, la localisation activée, et publiez-la. Le site doit retrouver tout seul l'endroit et la date.
  • L'export : téléchargez les relevés sous forme de tableau.
📝 Notez tout ce qui vous surprend, ce qui ne marche pas ou ce qui n'est pas clair. Une capture d'écran avec une phrase d'explication, c'est parfait.

Arrêter et relancer

6 Arrêter le site quand vous avez fini

Dans le dossier tester-le-site, double-cliquez sur arreter-windows.

Comme à l'étape 3 : dans le Terminal, collez sh , glissez le fichier arreter-mac.sh, puis Entrée.

Vos essais sont gardés pour la prochaine fois.

Pour relancer plus tard : ouvrez Docker Desktop, attendez Engine running, puis refaites l'étape 3. Ce sera beaucoup plus rapide que la première fois.

Pour aller plus loin (facultatif)

7 Accéder à l'espace d'administration

L'administration sert à vérifier les photos publiées et à gérer les stations. Le site doit être démarré.

Dans le dossier tester-le-site, double-cliquez sur creer-admin-windows.

Dans le Terminal, collez sh , glissez le fichier creer-admin-mac.sh, puis Entrée.

La fenêtre vous pose trois questions. Tapez la réponse puis Entrée à chaque fois :

  1. Username : un nom d'utilisateur, par exemple admin.
  2. Email address : vous pouvez laisser vide et appuyer directement sur Entrée.
  3. Password puis Password (again) : un mot de passe, deux fois. Il ne s'affiche pas pendant que vous le tapez : c'est normal.

La page https://localhost/admin s'ouvre ensuite : connectez-vous avec ce nom et ce mot de passe.

8 Mettre à jour les données IGN

Le contour du bassin, les cours d'eau et les sources viennent de l'IGN, qui les met à jour de temps en temps. Cette étape les télécharge à nouveau et les recharge dans le site. Le site doit être démarré.

Dans le dossier tester-le-site, double-cliquez sur mettre-a-jour-donnees-windows.

Dans le Terminal, collez sh , glissez le fichier mettre-a-jour-donnees-mac.sh, puis Entrée.

Cela prend quelques minutes. Quand la fenêtre affiche C'est fait !, rechargez la page du site. Vos photos et vos stations sont gardées.

Un problème ?

Ce que vous voyezCe qu'il faut faire
« Docker Desktop n'est pas démarré » Ouvrez Docker Desktop, attendez Engine running, puis refaites l'étape 3.
no configuration file provided Le dossier n'est sans doute pas décompressé. Refaites l'étape 2.
port is already allocated ou address already in use Un autre logiciel utilise la même « porte » que le site (Skype par exemple). Fermez-le ou redémarrez l'ordinateur, puis refaites l'étape 3.
« Le site met trop de temps à démarrer » Redémarrez Docker Desktop (clic droit sur la baleine → Restart), puis refaites l'étape 3.
No such file or directory dans le Terminal Le fichier n'a pas été bien glissé. Vérifiez qu'il y a un espace après sh et recommencez.
La page ne s'affiche pas Attendez une minute, puis rechargez la page. Vérifiez que l'adresse est bien https://localhost.
Autre chose Faites une capture d'écran de la fenêtre noire et envoyez-la à l'équipe, en expliquant ce que vous faisiez.
